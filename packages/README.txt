Compilation hints:
From the root directory (this README location) you can compile each problem separately.
Example for Problem1:
javac Problem1/college/student/Student.java Problem1/college/faculty/Faculty.java Problem1/Main.java
java -cp Problem1 Main

For package-based programs ensure you run javac from the root so package folder structure is found.

Note: Problem4 is modular; follow Problem4/README.txt for module compile/run commands.
